# VIP Landmark — website

Static site for VIP Landmark, Kothakote, Bagepalli (promoter Honey Agro Farms, marketed by AEVUM Ventures).
Single page: `index.html` plus `images/`. No build step, no server code.

Hosting: upload everything as-is, or enable GitHub Pages (Settings → Pages → Deploy from branch `main`, root)
and point viplandmark.in to it with a `CNAME` file. Full notes in `README.txt`.
